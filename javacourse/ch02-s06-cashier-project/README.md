# 2-6 章项目：收银台

**板块编号：** c2s6　|　**所属：** 第 2 章　|　**练习项目：** `ch02-s06-cashier-project`

## 🎯 练习目标
综合运用变量、类型、运算与 Scanner，写出一个能算账找零的收银台程序。

## 📋 练习步骤
1. 用 Scanner 依次接收商品名、单价、数量、折扣和付款金额五个输入。
2. 计算原价合计 totalPrice = 单价 × 数量。
3. 计算应付金额 payable = 原价合计 × 折扣，再算找零 change = 付款金额 − 应付金额。
4. 按小票格式逐行打印商品、单价、数量、原价合计、折扣、应付金额、付款和找零。
5. 给每一步计算补上注释，并检查变量名是否见名知意、缩进是否整齐。
