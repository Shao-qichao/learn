### 3.2 安装 JDK（Java 开发工具包）

#### JDK 版本怎么选？

Java 目前有多个活跃版本，对于零基础学习者，推荐 **JDK 11（LTS）** 或 **JDK 21（LTS）**：

| 版本 | 类型 | 是否推荐 | 说明 |
|------|------|---------|------|
| JDK 8 | LTS | ⚠️ 可用但偏旧 | 老项目仍广泛使用，但缺少现代语法特性 |
| JDK 11 | LTS | ✅ **推荐** | 本课程的练习代码基于 JDK 11 编写，兼容性最好 |
| JDK 17 | LTS | ✅ 兼容 | 支持 record、switch 表达式等新语法 |
| JDK 21 | LTS | ✅ 兼容 | 最新长期支持版，支持虚拟线程等特性 |
| JDK 22/23 | 非 LTS | ❌ 不推荐 | 非稳定版，不建议用于学习 |

> **LTS = Long Term Support**（长期支持版），稳定且有长期更新保证。本课程的所有练习在 JDK 11/17/21 上均可正常编译运行。

#### 下载安装步骤

1. 访问 https://adoptium.net/（Eclipse Temurin，免费开源）
2. 选择 **JDK 11（LTS）**（与课程练习完全匹配）
3. 选择对应操作系统：
   - Windows：选 `.msi` 安装包（64-bit x64）
   - macOS：选 `.pkg` 安装包（Apple Silicon 选 ARM64，Intel 选 x64）
   - Linux：选 `.tar.gz` 或按发行版用包管理器安装
4. 下载并运行安装程序
5. Windows 安装时勾选：
   - ✅ **"Associate .jar"**（关联 jar 文件）
   - ✅ **"JAVA_HOME variable"**（自动设置环境变量）
   - ✅ **"Add to PATH"**（添加到系统路径）

#### 验证安装

打开终端（PowerShell / 终端 / CMD），输入：

```
java -version
```

如果看到类似输出，说明安装成功：
```
openjdk version "11.0.22" 2024-01-16
OpenJDK Runtime Environment Temurin-11.0.22+9
OpenJDK 64-Bit Server VM Temurin-11.0.22+9
```

再输入：
```
javac -version
```
能看到编译器版本号，说明 JDK（而非仅 JRE）已正确安装。

#### 环境变量配置

**情况一：用 `.msi` 安装包且勾选了 "Set JAVA_HOME" 和 "Add to PATH"** —— 安装程序已自动配好，无需手动配置，直接按上面验证即可。

**情况二：手动配置（Windows）** —— 适用于忘勾选项、或用 zip 解压版的情况：

1. 按 `Win + R`，输入 `sysdm.cpl` 回车 → **高级** 选项卡 → **环境变量**
2. 在「系统变量」区点 **新建**：
   - 变量名：`JAVA_HOME`
   - 变量值：JDK 安装目录，例如 `C:\Program Files\Eclipse Adoptium\jdk-11.0.28+6`
     （默认安装在这个位置，"jdk-" 后面是具体版本号，打开文件夹确认一下）
3. 在「系统变量」区找到 `Path` → **编辑** → **新建** → 输入 `%JAVA_HOME%\bin` → 一路 **确定**
4. **关闭并重新打开**终端（旧窗口读不到新变量），输入 `java -version` 验证

常见坑：
- 配完不生效 → 99% 是没重开终端
- `javac` 找不到但 `java` 正常 → `Path` 里的 `%JAVA_HOME%\bin` 没加或写错
- 变量值末尾不要带分号，不要指向 `bin` 本身（应指向 JDK 根目录）

**macOS**：`.pkg` 安装自动配置。手动解压版在 `~/.zshrc` 中加入：
```bash
export JAVA_HOME=$(/usr/libexec/java_home)
export PATH=$JAVA_HOME/bin:$PATH
```
然后执行 `source ~/.zshrc` 生效。

**Linux**：用包管理器（apt/yum/dnf）安装会自动配置。手动解压版（如解压到 `/opt/jdk-11`）在 `~/.bashrc` 中加入：
```bash
export JAVA_HOME=/opt/jdk-11
export PATH=$JAVA_HOME/bin:$PATH
```
然后执行 `source ~/.bashrc` 生效。

#### 常见 JDK 问题

**Q: 已安装 JDK 但终端提示 `java: command not found`**
A: 环境变量未生效。Windows 重启终端或电脑；macOS/Linux 执行 `source ~/.bashrc` 或 `source ~/.zshrc`。

**Q: 系统上有多个 JDK 版本，怎么切换？**
A: Windows：在"系统环境变量"中调整 `JAVA_HOME` 指向想要的版本目录，确保 `%JAVA_HOME%\bin` 在 PATH 最前面。macOS：用 `jenv` 或 `/usr/libexec/java_home` 管理。

**Q: 练习代码报错 "不支持发行版本"**
A: 说明 JDK 版本低于代码要求的版本。升级到 JDK 11 或更高即可。

## 5. 学习流程详解

### 5.1 单个板块的学习流程

每个知识板块需要完成 **4 步** 才能解锁下一板块：

```
┌──────────────────────────────────────────────────┐
│  步骤 1: 阅读图文讲解                              │
│  → 仔细阅读文字内容，理解概念                       │
│  → 滚动到板块底部，系统自动标记 "已读 ✓"             │
├──────────────────────────────────────────────────┤
│  步骤 2: 完成闯关测验                              │
│  → 2-5 道选择题，需达到 80% 正确率                  │
│  → 点击选项后立即显示对错                           │
│  → 答错会显示解析，可重做                           │
│  → 达标后显示 "测验通过 ✓"                          │
├──────────────────────────────────────────────────┤
│  步骤 3: 查看参考答案                              │
│  → 点击 "查看参考答案" 按钮                         │
│  → 参考答案在页面内展开（不跳转新页面）               │
│  → 系统标记 "已查看 ✓"                              │
├──────────────────────────────────────────────────┤
│  步骤 4: 动手练习（用 VS Code 打开）                 │
│  → 点击 "用 VS Code 打开" 按钮                      │
│  → 在 VS Code 中按练习步骤编写代码                  │
│  → 编译运行验证结果                                 │
│  → 这一步是可选的，不影响解锁                        │
└──────────────────────────────────────────────────┘
```

### 5.2 如何知道一个板块已通关？

看板块右上角的进度条，显示 `100%` 且变绿色，表示该板块已通关。

也可以看章节顶部的通关进度条，每个小圆点代表一个板块：
- `○` = 未完成
- `✓` = 已完成

### 5.3 侧边栏导航

- **已解锁**的板块：正常可点击进入
- **未解锁**的板块：显示锁定图标，点击会提示解锁条件
- **章节项目**：每章最后一个板块，需要前面所有板块通关后才能进入

## 6. 闯关与解锁机制

### 6.1 板块解锁条件

完成当前板块需要同时满足：
1. **已读**：滚动到板块底部（自动标记）
2. **测验通过**：正确率 ≥ 80%
3. **查看参考答案**：点击查看按钮

三个条件全部满足后，下一板块自动解锁。

### 6.2 章节解锁（口令机制）

完成每章的**章节项目**后，会弹出一个**通关口令弹窗**：

```
┌──────────────────────────────────┐
│  🎉 恭喜完成第 1 章！             │
│                                  │
│  下一章解锁口令：                  │
│  ┌──────────────────┐            │
│  │  COFFEE-02       │  [复制]   │
│  └──────────────────┘            │
│                                  │
│  [直接进入第 2 章]                 │
└──────────────────────────────────┘
```

- 点击 **[复制]** 复制口令
- 点击侧边栏下一章，输入口令即可解锁
- 口令也可以手动输入（不区分大小写）

### 6.3 各章节口令

| 章节 | 口令 |
|------|------|
| 第 1 章 → 第 2 章 | COFFEE-02 |

| 第 3 章 → 第 4 章 | ARRAY-0404 |
| 第 4 章 → 第 5 章 | METHOD-0505 |
| 第 5 章 → 第 6 章 | OBJECT-0606 |
| 第 6 章 → 第 7 章 | EXTEND-0707 |
| 第 7 章 → 第 8 章 | FINAL-0808 |
| 第 8 章 → 第 9 章 | DSALGO-09 |

### 6.4 重置进度

如果需要重新开始，点击侧边栏底部的 **[重置进度]** 按钮：
- 会弹出确认框
- 确认后清除所有通关记录
- 回到第 1 章第 1 节

## 7. VS Code 练习操作


2. 在 VS Code 中打开 `src/Main.java`

3. 找到 `// TODO:` 注释，按提示编写代码

4. 运行代码：
   - 方法一：终端输入 `javac src/Main.java && java -cp src Main`
   - 方法二：用练习文件夹中的 `run.bat`（Windows）

5. 对照**预期结果**验证输出是否正确

## 9. 常见问题

### Q: 浏览器打开 index.html 是空白页

**A:** 检查浏览器是否支持 JavaScript。使用 Edge 或 Chrome。按 F12 打开开发者工具，看 Console 标签是否有红色错误。

### Q: 点击"用 VS Code 打开"没反应

**A:** 
1. 确认已安装 VS Code
2. 浏览器可能拦截了 `vscode://` 协议，检查地址栏右侧是否有提示
3. 备用方案：点击 **[📋 复制路径]**，手动在 VS Code 中打开文件夹

### Q: 练习代码编译报错

**A:**
1. 确认已安装 JDK（终端输入 `java -version` 能看到版本）
2. 中文路径可能导致问题，确保路径中没有特殊字符
3. 使用 `run.bat` 一键编译运行

### Q: 测验答错了怎么办

**A:** 可以重做。重新选择答案即可，系统取最高分。答错时会显示解析，帮助理解。

### Q: 忘了口令怎么办

**A:** 
1. 重新完成该章节项目，会再次弹出
2. 查看本指南的 [口令表](#63-各章节口令)
3. 点击侧边栏 **[重置进度]** 从头开始（会清除所有记录）

### Q: 进度丢失了

**A:** 进度保存在浏览器本地存储中。如果清理了浏览器缓存，进度会丢失。建议：
- 不要在隐私/无痕模式下使用
- 不要清理浏览器 localStorage

### Q: GitHub 连接超时

**A:**
- 国内网络可能需要代理/VPN
- 脚本会自动检测系统代理
- 可手动配置：`git config --global http.proxy "http://127.0.0.1:7897"`

### Q: 想在另一台电脑上继续学习

**A:**
1. 在新电脑上运行一键安装脚本
2. 打开 index.html 即可
3. 进度是浏览器本地存储，不跨设备同步

---

> 遇到其他问题？检查 `tools/` 目录下的日志文件，或重新运行安装脚本。
