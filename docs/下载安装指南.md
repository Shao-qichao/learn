# Java 学习中心 · 下载与安装指南

> 桌面版把课程网站打包成了独立软件：双击图标即可学习，无需手动 clone 项目、无需修改任何路径。

---

## 一、下载

### 方式一：GitHub Releases（推荐）

1. 打开仓库主页：<https://github.com/Shao-qichao/learn>
2. 点击右侧的 **Releases**（或直接访问 <https://github.com/Shao-qichao/learn/releases>）
3. 在最新版本的 **Assets** 区域，根据操作系统下载对应安装包：

| 操作系统 | 下载文件 | 说明 |
|---------|---------|------|
| Windows 10/11（64 位） | `Java学习中心-Setup-1.0.0.exe` | NSIS 安装程序 |
| macOS（Apple 芯片 M 系列） | `Java学习中心-1.0.0-arm64.dmg` | M1/M2/M3/M4 |
| macOS（Intel 芯片） | `Java学习中心-1.0.0-x64.dmg` | 较老的 Intel 机型 |
| Linux（Ubuntu/Debian） | `Java学习中心-1.0.0-x86_64.deb` | 双击或 `sudo dpkg -i` 安装 |
| Linux（通用） | `Java学习中心-1.0.0-x86_64.AppImage` | 加可执行权限后直接运行 |

> 国内访问 GitHub 下载慢时，可在 Release 页面右键复制下载链接，用下载工具（如迅雷）下载。

### 方式二：从源码运行（面向开发者）

见 [开发者文档](开发者文档.md)。

## 二、安装

### Windows

1. 双击 `Java学习中心-Setup-1.0.0.exe`
2. 若弹出 **Windows 已保护你的电脑**（因为未做付费代码签名）：
   - 点击 **更多信息**
   - 点击 **仍要运行**
3. 选择安装目录（默认即可），点击安装
4. 安装结束后，桌面和开始菜单会出现 **Java学习中心** 快捷方式
5. 双击图标启动软件

> 本软件为**按用户安装**，不需要管理员密码。

### macOS（Apple Silicon / Intel）

1. 打开下载的 `.dmg` 文件
2. 将 **Java学习中心** 拖入 **Applications（应用程序）** 文件夹
3. 首次打开时若提示「无法验证开发者」：
   - 打开 **系统设置 → 隐私与安全性**
   - 找到被拦截的提示，点击 **仍要打开**
4. 从启动台（Launchpad）启动

### Linux

**Debian / Ubuntu（.deb）：**
```bash
sudo dpkg -i Java学习中心-1.0.0-x86_64.deb
# 如提示依赖缺失，执行：
sudo apt-get install -f
```

**AppImage（通用）：**
```bash
chmod +x Java学习中心-1.0.0-x86_64.AppImage
./Java学习中心-1.0.0-x86_64.AppImage
```

## 三、首次启动后会发生什么

软件启动时会自动完成以下准备工作（无需手动操作）：

```
1. 在「文档」文件夹下创建 Java学习中心 工作目录
2. 把 55 个练习模板复制到 文档/Java学习中心/javacourse/
3. 创建 文档/Java学习中心/JavaLearning/（用于写章节项目）
4. 自动把课程内所有路径适配为当前电脑的真实路径
```

### 我的代码在哪里？

| 目录 | 内容 |
|------|------|
| `文档/Java学习中心/javacourse/` | 55 个随堂动手练习（模板的可写副本，可随意改） |
| `文档/Java学习中心/JavaLearning/` | 10 个章节项目代码（个人名片、收银台、图书馆等） |

> Windows 上如果你的「文档」文件夹被重定向到了其他盘（如 D 盘），工作目录会跟随到真实的文档位置。

**安全机制**：软件每次启动只**补齐缺失**的练习文件夹，你已经修改过的代码永远不会被覆盖。

也可以在软件菜单 **学习 → 打开练习文件夹 / 打开章项目文件夹** 直接定位。

## 四、学习前还需要装什么？

桌面软件本身是「课程 + 练习环境引导」，真正写 Java 代码仍需要：

| 软件 | 用途 | 必要性 |
|------|------|--------|
| JDK 11+ | 编译运行 Java 代码 | 必装 |
| VS Code | 编辑代码（课程内按钮一键唤起） | 推荐 |
| Git | 从仓库拉取项目（用桌面版学习则不需要） | 可选 |

安装方法见课程仓库中 `java-course-site/新用户操作指南.md` 的第 3 节，或运行 `java-course-site/tools/` 下的一键安装脚本。

## 五、卸载

- **Windows**：设置 → 应用 → 已安装的应用 → Java学习中心 → 卸载
- **macOS**：从应用程序文件夹把 Java学习中心 拖到废纸篓
- **Linux (deb)**：`sudo apt remove java-learning-center`

卸载**不会**删除 `文档/Java学习中心/` 里你写的代码，也不会清除浏览器式的学习进度（进度存于系统应用数据目录，如需彻底清除可手动删除该目录）。

## 六、常见问题

**Q: Windows 安装时提示 SmartScreen 拦截？**
A: 软件未购买商业代码签名证书，属正常现象。点「更多信息 → 仍要运行」即可。

**Q: 点击「用 VS Code 打开」没反应？**
A: 请先安装 VS Code。也可以用菜单「学习 → 打开练习文件夹」找到代码文件，手动拖进 VS Code。

**Q: 学习进度会丢吗？**
A: 进度保存在系统应用数据中，正常关闭软件不会丢。使用菜单中的「清空学习进度」才会重置。

**Q: 软件升级后我写的代码还在吗？**
A: 在。代码在「文档/Java学习中心/」，与软件安装目录相互独立，升级不影响。

**Q: 和直接用网页版（index.html）有什么区别？**
A: 桌面版自带路径适配（换电脑、换用户名都能直接用）、练习模板自动部署、独立窗口和开始菜单快捷方式，功能内容与网页版完全一致。
