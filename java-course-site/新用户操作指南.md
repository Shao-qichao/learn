## 1. 这是什么项目

Java 学习中心是一个**闯关式**的 Java 零基础学习网站，包含：

- **10 个章节**，共 **57 个知识板块**
- 每个板块包含：图文讲解 + 闯关测验 + 动手练习
- 每章末尾有**章节项目**（实战编码）
- 完成一章才能解锁下一章（口令机制）

```
第1章 Java 入门          （6 个板块 + 个人名片项目）
第2章 变量与数据类型       （6 个板块 + 收银台项目）
第3章 运算符与流程控制     （6 个板块 + 判断闰年项目）
第4章 数组                （5 个板块 + 成绩统计项目）
第5章 方法                （6 个板块 + 菜单系统项目）
第6章 面向对象基础         （6 个板块 + 学生类项目）
第7章 继承与多态           （6 个板块 + 动物园项目）
第8章 综合项目            （7 个板块 + 图书馆系统）
第9章 数据结构与算法       （5 个板块 + 排序实战）
第10章 文件与进阶         （4 个板块 + 音乐播放器）
```

## 2. 环境准备（一键安装）

### Windows 用户（推荐）

1. 下载本项目（或 git clone）
2. 打开 **PowerShell**（开始菜单搜索 PowerShell）
3. 运行一键安装脚本：

```powershell
powershell -ExecutionPolicy Bypass -File "java-course-site\tools\setup-windows.ps1"
```

脚本会自动完成：
- 检测系统环境
- 安装 Git + JDK + VS Code
- 配置 Git 用户信息
- 克隆项目到 `D:\java学习中心`
- 适配当前用户路径
- 验证安装结果

> 按提示输入 Git 用户名和邮箱，全程约 5-10 分钟。

### macOS / Linux 用户

```bash
chmod +x java-course-site/tools/setup-mac-linux.sh
./java-course-site/tools/setup-mac-linux.sh
```

## 3. 手动安装（备用方案）

如果一键脚本失败，可手动安装：

### 3.1 安装 Git

| 平台 | 下载地址 |
|------|---------|
| Windows | https://git-scm.com/download/win |
| macOS | 终端运行 `git` 会自动弹出安装提示 |
| Linux | `sudo apt install git` 或 `sudo yum install git` |

### 3.2 安装 JDK（Java 开发工具包）

1. 访问 https://adoptium.net/
2. 选择 **JDK 11（LTS）** 或更高版本
3. 下载对应操作系统的安装包
4. 安装时勾选 **"将 JAVA_HOME 添加到系统变量"**

验证安装：打开终端输入
```
java -version
```
能看到版本号即安装成功。

### 3.3 安装 VS Code（代码编辑器）

1. 访问 https://code.visualstudio.com/
2. 下载并安装
3. 安装时勾选 **"添加到 PATH"**

### 3.4 克隆项目

```powershell
# Windows
git clone https://github.com/Shao-qichao/learn.git "D:\java学习中心"

# macOS / Linux
git clone https://github.com/Shao-qichao/learn.git ~/java学习中心
```

### 3.5 创建 JavaLearning 目录

章项目代码写在这里：
```powershell
# Windows
mkdir "$env:USERPROFILE\JavaLearning"

# macOS / Linux
mkdir ~/JavaLearning
```

### 3.6 适配用户路径（仅 Windows，用户名不是 13053 时）

如果你的 Windows 用户名不是 `13053`，运行：
```powershell
$f = "D:\java学习中心\java-course-site\index.html"
$t = $env:USERPROFILE -replace '\\','/'
(Get-Content $f -Encoding UTF8) -replace 'c:/Users/13053/JavaLearning',($t + '/JavaLearning') | Set-Content $f -Encoding UTF8
```

## 5. 学习流程详解

### 5.1 单个板块的学习流程

每个知识板块需要完成 **4 步** 才能解锁下一板块：

```
┌──────────────────────────────────────────────────┐
│  步骤 1: 阅读图文讲解                              │
│  → 仔细阅读文字内容，理解概念                       │
│  → 滚动到板块底部，系统自动标记 "已读 ✓"             │
├──────────────────────────────────────────────────┤
│  步骤 2: 完成闯关测验                              │
│  → 2-5 道选择题，需达到 80% 正确率                  │
│  → 点击选项后立即显示对错                           │
│  → 答错会显示解析，可重做                           │
│  → 达标后显示 "测验通过 ✓"                          │
├──────────────────────────────────────────────────┤
│  步骤 3: 查看参考答案                              │
│  → 点击 "查看参考答案" 按钮                         │
│  → 参考答案在页面内展开（不跳转新页面）               │
│  → 系统标记 "已查看 ✓"                              │
├──────────────────────────────────────────────────┤
│  步骤 4: 动手练习（用 VS Code 打开）                 │
│  → 点击 "用 VS Code 打开" 按钮                      │
│  → 在 VS Code 中按练习步骤编写代码                  │
│  → 编译运行验证结果                                 │
│  → 这一步是可选的，不影响解锁                        │
└──────────────────────────────────────────────────┘
```

### 5.2 如何知道一个板块已通关？

看板块右上角的进度条，显示 `100%` 且变绿色，表示该板块已通关。

也可以看章节顶部的通关进度条，每个小圆点代表一个板块：
- `○` = 未完成
- `✓` = 已完成

### 5.3 侧边栏导航

- **已解锁**的板块：正常可点击进入
- **未解锁**的板块：显示锁定图标，点击会提示解锁条件
- **章节项目**：每章最后一个板块，需要前面所有板块通关后才能进入

## 6. 闯关与解锁机制

### 6.1 板块解锁条件

完成当前板块需要同时满足：
1. **已读**：滚动到板块底部（自动标记）
2. **测验通过**：正确率 ≥ 80%
3. **查看参考答案**：点击查看按钮

三个条件全部满足后，下一板块自动解锁。

### 6.2 章节解锁（口令机制）

完成每章的**章节项目**后，会弹出一个**通关口令弹窗**：

```
┌──────────────────────────────────┐
│  🎉 恭喜完成第 1 章！             │
│                                  │
│  下一章解锁口令：                  │
│  ┌──────────────────┐            │
│  │  COFFEE-02       │  [复制]   │
│  └──────────────────┘            │
│                                  │
│  [直接进入第 2 章]                 │
└──────────────────────────────────┘
```

- 点击 **[复制]** 复制口令
- 点击侧边栏下一章，输入口令即可解锁
- 口令也可以手动输入（不区分大小写）

### 6.3 各章节口令

| 章节 | 口令 |
|------|------|
| 第 1 章 → 第 2 章 | COFFEE-02 |
| 第 2 章 → 第 3 章 | LOOP-0303 |
| 第 3 章 → 第 4 章 | ARRAY-0404 |
| 第 4 章 → 第 5 章 | METHOD-0505 |
| 第 5 章 → 第 6 章 | OBJECT-0606 |
| 第 6 章 → 第 7 章 | EXTEND-0707 |
| 第 7 章 → 第 8 章 | FINAL-0808 |
| 第 8 章 → 第 9 章 | DSALGO-09 |
| 第 9 章 → 第 10 章 | MUSIC-10 |

### 6.4 重置进度

如果需要重新开始，点击侧边栏底部的 **[重置进度]** 按钮：
- 会弹出确认框
- 确认后清除所有通关记录
- 回到第 1 章第 1 节

## 7. VS Code 练习操作

### 7.1 打开练习

每个板块底部有练习卡片：

```
┌──────────────────────────────────────────────────┐
│  练习目标：理解 Java 的跨平台特性                   │
│                                                  │
│  练习路径：D:\java学习中心\javacourse\ch01-s01-...  │
│                                                  │
│  [🖥 用 VS Code 打开]  [📄 直接打开 Main.java]      │
│  [📋 复制路径]         [👁 查看参考答案]             │
│                                                  │
│  练习步骤：                                       │
│  1. 打开 Main.java                               │
│  2. 按 TODO 注释完成代码                           │
│  3. 运行验证结果                                  │
│                                                  │
│  预期结果：输出 Hello, Java!                       │
└──────────────────────────────────────────────────┘
```

### 7.2 在 VS Code 中操作

1. 点击 **[用 VS Code 打开]**
   - 浏览器会弹出确认框，选择 **"打开 VS Code"**
   - 勾选 **"始终允许"** 可避免下次再弹

2. 在 VS Code 中打开 `src/Main.java`

3. 找到 `// TODO:` 注释，按提示编写代码

4. 运行代码：
   - 方法一：终端输入 `javac src/Main.java && java -cp src Main`
   - 方法二：用练习文件夹中的 `run.bat`（Windows）

5. 对照**预期结果**验证输出是否正确

### 7.3 查看参考答案

如果卡住了，点击 **[👁 查看参考答案]**：
- 参考答案在页面内展开
- 建议先自己尝试，实在做不出再看
- 查看后系统标记该板块的"参考答案已查看"


## 9. 常见问题

### Q: 浏览器打开 index.html 是空白页

**A:** 检查浏览器是否支持 JavaScript。使用 Edge 或 Chrome。按 F12 打开开发者工具，看 Console 标签是否有红色错误。

### Q: 点击"用 VS Code 打开"没反应

**A:** 
1. 确认已安装 VS Code
2. 浏览器可能拦截了 `vscode://` 协议，检查地址栏右侧是否有提示
3. 备用方案：点击 **[📋 复制路径]**，手动在 VS Code 中打开文件夹

### Q: 练习代码编译报错

**A:**
1. 确认已安装 JDK（终端输入 `java -version` 能看到版本）
2. 中文路径可能导致问题，确保路径中没有特殊字符
3. 使用 `run.bat` 一键编译运行

### Q: 测验答错了怎么办

**A:** 可以重做。重新选择答案即可，系统取最高分。答错时会显示解析，帮助理解。

### Q: 忘了口令怎么办

**A:** 
1. 重新完成该章节项目，会再次弹出
2. 查看本指南的 [口令表](#63-各章节口令)
3. 点击侧边栏 **[重置进度]** 从头开始（会清除所有记录）

### Q: 进度丢失了

**A:** 进度保存在浏览器本地存储中。如果清理了浏览器缓存，进度会丢失。建议：
- 不要在隐私/无痕模式下使用
- 不要清理浏览器 localStorage

### Q: GitHub 连接超时

**A:**
- 国内网络可能需要代理/VPN
- 脚本会自动检测系统代理
- 可手动配置：`git config --global http.proxy "http://127.0.0.1:7897"`

### Q: 想在另一台电脑上继续学习

**A:**
1. 在新电脑上运行一键安装脚本
2. 打开 index.html 即可
3. 进度是浏览器本地存储，不跨设备同步

---

> 遇到其他问题？检查 `tools/` 目录下的日志文件，或重新运行安装脚本。
