## 🎯 练习目标
通过计算两个整数的和差积商余，掌握算术、赋值、自增与关系运算符的用法。

## 📋 练习步骤
1. 声明两个 int 变量 a、b 并赋初值，用加号拼接打印它们的和与差。
2. 用乘号打印 a * b 的结果，再用除号求 a 除以 b 的商。
3. 用取余符号 % 求 a 除以 b 的余数并打印，体会整数除法的截断。
4. 用关系运算符打印 a > b、a == b 的 boolean 结果。
