第1章 Java 入门 / 板块 1-1

1Java 是什么？能用来干什么？

一句话版

🔑 记住这句话Java 是一门编程语言——一种"你和电脑对话的语言"。你用它写下指令，电脑就照做。

白话版

电脑本身很笨，它只认识 0 和 1。人不可能直接写 010101，所以人类发明了编程语言：

  • 你用接近英语的单词写指令（比如 System.out.println）
  • 再由一个"翻译工具"把它翻译成电脑懂的东西
  • 电脑执行后给你结果

Java 就是这样的语言之一，同类的还有 Python、C++、JavaScript 等。JavaScript 是给网页用的，Java 主要给"后台服务器"用，两者名字像但没有亲戚关系，就像"雷锋"和"雷峰塔"。

Java 能做什么？

  1. 网站后台：淘宝下单时处理订单、扣库存的服务器，很多是 Java 写的
  2. 安卓 App：安卓手机上的应用大量用 Java（或近亲 Kotlin）
  3. 企业软件：银行系统、公司内部管理系统
  4. 大数据：处理海量数据的工具很多跑在 Java 上

最大特点：一次编写，到处运行

同一个 Java 程序，不用改代码就能在 Windows、Mac、Linux 上运行，这叫跨平台（又叫平台无关性）。

普通程序像"只配米饭吃的菜"，换个盘子就不能吃；Java 程序像"自热火锅"，自带加热包——这个加热包就是下一个板块要讲的 JVM（Java 虚拟机）。

例子：你写过的第一个程序

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello,World!");
    }
}

这段代码在 Windows 上能跑，原封不动拷到 Mac 上一样能跑。现在看不懂每一行没关系，板块 1-4 会逐行拆开。

2JDK、JRE、JVM 三个名词

一句话版

🔑 记住这句话三个东西是套娃关系：JDK 里面有 JRE，JRE 里面有 JVM。我们写代码的人，装 JDK 就对了。

用"拍视频 vs 看视频"来理解

名词全称（不用背）是什么生活类比
JVMJava Virtual Machine真正运行 Java 程序的"虚拟电脑"视频播放器（负责播放）
JREJava Runtime Environment运行环境 = JVM + 官方提供的"现成零件库"（类库）播放器 + 影片资源库
JDKJava Development Kit开发工具包 = JRE + 编译器 javac 等开发工具播放器 + 资源库 + 摄像机和剪辑软件

普通人只想用 Java 写的软件 → 装 JRE 就够；我们要写 Java 代码 → 必须装 JDK（因为里面有把源码翻译成字节码的编译器 javac）。

套娃关系图

┌─────────────── JDK（开发工具包，我们装这个）───────────────┐
│  编译器 javac、调试工具、打包工具……                          │
│  ┌──────────────── JRE（运行环境）────────────────┐         │
│  │   官方类库（现成零件：System.out 等）            │         │
│  │   ┌──────────── JVM（虚拟机，真正执行程序）──┐   │         │
│  │   │   你的 HelloWorld.class 在这里被运行     │   │         │
│  │   └──────────────────────────────────────────┘   │         │
│  └───────────────────────────────────────────────────┘         │
└────────────────────────────────────────────────────────────────┘
💡 补充新版 JDK（11 及以后）安装后不再单独显示 JRE 文件夹，但"JDK 包含运行 Java 所需的一切"这个结论不变。你电脑里能运行 java -version，就说明 JDK 已装好。

一个关键区分：javac 是谁的？

  • javac（编译命令）只存在于 JDK 里 → 没有 JDK 就不能编译自己的代码
  • java（运行命令）在 JRE/JDK 里都有 → 负责启动 JVM 跑程序

所以：能运行别人给的 .class 不代表能写代码；敲 javac 不报错，才证明装的是完整 JDK。

3开发环境与两个命令

一句话版

🔑 记住这句话写 Java 只需两步：javac 文件名.java 把源码编译成 .class，再用 java 类名（不带 .class）运行。

你的电脑上已经有什么

你的 JavaLearning 文件夹里已经同时存在 HelloWorld.java 和 HelloWorld.class，说明：

  • JDK 已安装成功（否则编译不出 .class）
  • VS Code 的 Java 运行环境已配好

所以安装环节你已经过关了，这个板块重点是搞懂"背后发生了什么"，以及怎么用命令行手动操作。

两种运行方式

方式一：VS Code（平时写代码用这个）

  • 打开 .java 文件 → 点右上角 ▶ 三角形按钮，或右键 → Run Java
  • 它会自动帮你"编译 + 运行"，结果显示在下方的"终端"窗口里

方式二：命令行手动操作（必须懂，面试/考试常考）

在 VS Code 里点菜单 终端 → 新建终端，然后输入：

# 第 1 步：编译（javac 来自 JDK），成功后文件夹里多出 HelloWorld.class
javac HelloWorld.java

# 第 2 步：运行（java 启动 JVM），注意写 HelloWorld，不带任何后缀
java HelloWorld

屏幕上就会出现：

Hello,World!
命令作用后面跟什么产生什么
javac编译：源码 → 字节码文件名带 .java生成同名 .class 文件
java运行：启动 JVM 执行类名，不带后缀屏幕输出结果
java -version查看 JDK 版本无显示版本号
⚠️ 最常见的手误 写成 java HelloWorld.class 或 java HelloWorld.java 都会报错。运行时 java 后面只写类名。

环境变量 PATH 是什么？（了解即可）

javac.exe、java.exe 这两个程序藏在 JDK 安装目录的 bin 文件夹里。终端输入命令时，系统会去一个叫 PATH 的"名单"里挨个文件夹找这个程序。

安装 JDK 时把 bin 目录加进 PATH，意思就是告诉系统："以后我在任何文件夹敲 java，都来这个位置找。"

💡 症状对照如果终端提示 'java' 不是内部或外部命令，99% 是 PATH 没配对；而你现在能正常运行，说明已经配好了。

4HelloWorld 逐行精讲

先看全貌

① public class HelloWorld {
②     public static void main(String[] args) {
③         System.out.println("Hello,World!");
④     }
⑤ }

整个程序就是一个"盒子套盒子"：类（大盒子）装着 main 方法（中盒子），main 里面装着一条条语句（要做的事）。

第 ① 行：public class HelloWorld {

片段含义
class关键字，声明一个类。类是 Java 程序的最小组织单位，所有代码都必须放在类里。
HelloWorld类名，由程序员自己起。这里类名叫 HelloWorld。
public"公开的"修饰符，现阶段照抄，后面章节会讲。
{类的开始，与最后一行的 } 配对。
⚠️ 文件名铁律（必背） 如果类前面加了 public，那么文件名必须和类名一模一样，连大小写都不能差。
类叫 HelloWorld → 文件必须叫 HelloWorld.java；写成 helloworld.java 编译就会报错。

第 ② 行：public static void main(String[] args) {

这一行定义了 main 方法——程序的大门。JVM 运行程序时，固定从 main 方法的第一行开始执行，没有 main 程序就无法启动。

片段现阶段怎么理解
public公开的，照抄
static静态的，照抄（第 6 章讲完面向对象自然懂）
void"空"，表示这个方法不返回结果，照抄
main方法名，必须叫 main，JVM 只认这个名字
String[] args方法的参数（运行时可传入的信息），现阶段照抄即可
🔑 本阶段唯一要求把这一行像电话号码一样背下来：public static void main(String[] args)。每个单词现在不懂没关系，但一个字母都不能写错（大小写错了程序照样跑不起来）。

第 ③ 行：System.out.println("Hello,World!");

  • System.out.println(...) = 调用 Java 自带的"打印工具"，把括号里的内容输出到屏幕并换一行
  • "Hello,World!" 双引号包起来的内容叫字符串：写什么字，屏幕就显示什么字（双引号本身不会显示）
  • 结尾的 ; 分号：Java 每条语句的结束标志，相当于中文句子的句号

对比：System.out.print("A"); 输出后不换行，println 里的 ln 就是 line（换行）的意思。这个第 3 章会经常用。

第 ④⑤ 行：两个右大括号 }

  • 第 ④ 行 } 关闭 main 方法
  • 第 ⑤ 行 } 关闭 HelloWorld 类
  • 大括号必须成对出现，少一个编译就会报错（1-5 板块会看到具体报错长什么样）

执行顺序：程序是怎么"走"的？

JVM 启动
  └─ 找到 main 方法（第②行）
       └─ 从上往下依次执行里面的语句
            └─ 执行第③行：屏幕打印 Hello,World!
       └─ main 里的语句全部执行完
  └─ 程序结束

记住两个顺序：代码从 main 开始；方法内部从上往下、一行一行执行。

易混点小结

符号作用
{ }成对出现，圈出类/方法的"身体"范围
( )方法名后跟括号，里面放参数；println 的内容就放在括号里
" "双引号，包住要显示的文字
;一条语句结束，几乎每行执行语句末尾都要有

  3. println 和 print 的区别是什么？

两个关键理解：

  1. .class 不是给某个系统用的机器码，而是给 JVM 看的"中间码"——所以 Windows 上编译出的 .class 拷到 Mac，由 Mac 的 JVM 一样能跑，这就是跨平台的真正秘密。
  2. 改完 .java 必须重新编译。你改了源码却没重新 javac，运行的还是旧 .class，会看到"代码改了但输出没变"。

1 个错误

1变量是什么

一句话版

🔑 记住这句话变量 = 内存里一个带名字的小盒子，用来装一个可以改变的数据。

白话版：酒店前台的寄存盒

电脑运行程序时，数据要放在内存里。你可以把内存想象成酒店前台一排排寄存盒：

  • 每个盒子上贴标签（变量名），比如"年龄"
  • 盒子里放东西（数据值），比如 18
  • 今年盒子里是 18，明年可以换成 19——盒子没变，里面的值可以变，所以叫"变量"

怎么创建一个变量（三步）

int age;        // ① 声明：贴标签。int 表示这个盒子只能装整数
age = 18;        // ② 赋值：把 18 放进盒子，= 读作"赋值为"
int score = 90;  // ③ 声明+赋值可以合并成一行（最常用）

等号 = 在 Java 里不是数学上的"等于"，而是"把右边的值，放进左边的盒子"。判断"是否相等"用 ==（两个等号），2-3 会讲。

变量可以反复改值

int count = 0;
count = 1;       // 重新赋值时，不用再写 int
count = count + 1; // 右边先算：取出旧值 1，加 1 得 2，再放回盒子
System.out.println(count); // 打印 2
⚠️ 新手常见错误 ① 声明过的变量再赋值时重复写类型：int count; int count = 2;（第二次的 int 要去掉）
② 变量没赋值就使用：int a; System.out.println(a); → 编译报错"可能尚未初始化变量"

变量命名规则（必须遵守）

规则✅ 合法❌ 非法
只能用字母、数字、下划线 _、美元符 $age、user_name、$priceuser-name（有减号）
不能以数字开头num22num
不能用 Java 关键字score1class、int、public
大小写敏感age 和 Age 是两个不同变量（但别故意这么起）

行业习惯（小驼峰命名）：第一个单词全小写，后面每个单词首字母大写，名字要有意义。

例如：studentAge、totalPrice、phoneNumber。不要用 a、bbb 这种无意义名字。

一个完整小例子

public class VariableDemo {
    public static void main(String[] args) {
        int age = 18;               // 我的年龄
        int nextYearAge = age + 1;  // 用变量参与计算

    }
}

4数据类型转换

一句话版

🔑 记住这句话小盒子倒进大盒子，自动转；大盒子硬塞进小盒子，必须手动强转（会丢精度）。

自动类型转换（隐式，不用写代码）

当"取值范围小"的类型遇上"取值范围大"的类型，Java 会自动把小的转成大的，安全不丢东西：

byte → short → int → long → float → double
           char ↗
int a = 10;
double b = a;   // ✅ 自动转换：int 的 10 变成 double 的 10.0
System.out.println(b); // 10.0

double avg = 10 / 4;
System.out.println(avg); // ⚠️ 2.0！10/4 先按整数相除得 2，再转成 2.0
double avg2 = 10.0 / 4;
System.out.println(avg2); // 2.5，有 double 参与，按小数除法算
⚠️ 求平均值最经典的坑两个 int 相除，结果先被砍成整数，再赋值给 double 也救不回来。想保留小数，就让其中一个数带小数点（或强转，见下）。

强制类型转换（显式，自己负责后果）

大范围 → 小范围，Java 不允许自动转（怕你把行李箱塞进鞋盒），必须由你亲自点头，格式：

(目标类型) 值

double price = 39.9;
int p = (int) price;  // 强制转换
System.out.println(p);   // 39，小数部分被直接砍掉（不是四舍五入！）

int total = 10, count = 4;
double avg = (double) total / count;
System.out.println(avg); // 2.5，先把 total 强转成 10.0，再做小数除法

  • int → byte 等：超出目标范围会得到奇怪的结果，现阶段不要这么做

char 与 int 也能互转（了解）

char c = 'A';
int code = c;
System.out.println(code); // 65（字符 A 在编码表中的编号）

🔑 记住这句话到目前为止程序只会"从上往下一条道走到黑"；if 让程序能根据条件，决定这段代码做还是不做。

3switch：多路选择（菜单专用）

一句话版

🔑 记住这句话当"一个变量等于哪个值，就做哪件事"时，用 switch 比一长串 else if 清爽——它就是 ATM、点餐机的菜单原理。

基本写法

int choice = 2;
switch (choice) {        // 小括号里放要判断的变量
    case 1:
        System.out.println("查询余额");
        break;        // 做完立刻跳出 switch
    case 2:
        System.out.println("存款");
        break;
    case 3:
        System.out.println("取款");
        break;
    default:            // 所有 case 都没命中时执行（相当于 else）
        System.out.println("无效选项");
        break;
}
  • case 值: 后面只能写固定值（1、2、'A'、字符串），不能写 score > 60 这种范围条件
  • 需要判断范围（分数段、年龄段）→ 用 else if；等值菜单选择 → 用 switch

忘记 break 会怎样？（case 穿透）

int n = 1;
switch (n) {
    case 1:
        System.out.println("一");   // 没有 break！
    case 2:
        System.out.println("二");   // 会继续穿透执行
    case 3:
        System.out.println("三");   // 一直执行到 break 或 switch 结束
        break;
    default:
        System.out.println("其他");
}

输出：一 二 三。命中 case 1 后，像"多米诺骨牌"一样一路往下执行。

⚠️ 90% 的 switch bug都是漏写 break 导致穿透。现阶段每个 case 老老实实写 break。（多个 case 共用同一段代码时，故意不写 break 才有用，了解即可。）

String day = "周六";

    case "周六":
    case "周日":
        System.out.println("睡个懒觉");
        break;
    default:
        System.out.println("早起上课");

}

上面故意演示"case 穿透的合理用法"：周六、周日都执行同一句"睡个懒觉"。注意字符串比较大小写必须完全一致。

4while 循环：让程序学会"重复"

一句话版

🔑 记住这句话while = 只要条件成立，就反复执行同一段代码。打印 100 遍"你好"不用写 100 行。

生活类比：跑操场

体育老师说：只要你还没跑完 5 圈，就继续跑。每跑一圈计数 +1，到 5 圈条件不成立，停下。循环三要素：起点（计数器初始值）、条件（跑到几圈）、变化（每圈 +1）。

while 语法与执行流程

int i = 1;          // ① 起点
while (i <= 5) {     // ② 条件：成立就执行循环体
    System.out.println("第 " + i + " 圈");
    i++;             // ③ 变化：每圈 +1（千万不能忘！）
}
     ┌─→ 判断 i<=5 ?
     │   true  → 打印 → i++ ─┘
     │   false → 跳出循环，继续往下
     └─（false 时离开）

死循环：少了"变化"会怎样

int i = 1;
while (i <= 5) {
    System.out.println("停不下来！");
    // 没有 i++，i 永远是 1，条件永远成立 → 死循环
}
⚠️ 救命按钮在终端/控制台里程序死循环停不下来时，按 Ctrl + C 强制终止。排查方法：检查循环变量有没有在循环体里改变。

do...while：先做一次再说（了解）

int j = 100;
do {
    System.out.println(j);   // 不管条件真假，先执行 1 次
    j++;
} while (j <= 5);           // 条件不成立，循环只跑了一次

while 先判断后执行（可能一次都不跑）；do-while 先执行后判断（至少跑一次）。ATM 菜单"先显示再等用户选择"天然适合 do-while。

循环小练习：1+2+...+100

int i = 1;
int sum = 0;        // 累加器，起点必须是 0
while (i <= 100) {
    sum = sum + i;  // 把 i 累加进 sum
    i++;
}
System.out.println(sum); // 5050

套路：累加器清零 → 循环里反复 sum += i → 循环外打印结果。求乘积则累乘器起点设 1。

break：提前跳出循环

int i = 1;
while (true) {              // while(true) 是故意写的死循环
    if (i > 3) {
        break;           // i 到 4 时跳出，死循环被 break 终结
    }
    System.out.println(i);
    i++;
} // 输出 1 2 3

5for 循环与 break/continue

一句话版

🔑 记住这句话循环次数明确时用 for（最常用），次数不明确、靠条件结束时用 while。

for 语法：三要素写在一行

for (int i = 1; i <= 5; i++) {
    System.out.println("第 " + i + " 次");
}
括号内三部分对应循环三要素执行时机
int i = 1起点整个循环开始前执行一次
i <= 5条件每轮开始前判断，false 就结束
i++变化每轮循环体执行完之后执行

上面代码等价于 3-4 的 while 写法，只是把 i 的声明、判断、自增压到了一行，更紧凑、不易漏写 i++。

常用套路

// 1~100 求和
int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum += i;
}
// 打印 10 以内偶数
for (int i = 0; i <= 10; i += 2) {
    System.out.println(i);
}
// 倒计时 3 2 1
for (int i = 3; i >= 1; i--) {
    System.out.println(i);
}

continue：跳过本轮，继续下一轮

// 打印 1~10，但跳过 5
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        continue;   // 本轮后面的代码不做，直接进入 i++ 和下一轮判断
    }
    System.out.println(i);
} // 1 2 3 4 6 7 8 9 10（没有 5）
关键字作用生活类比
break立刻结束整个循环跑步受了伤，今天直接结束
continue只跳过本轮，继续下一轮这一圈鞋带散了，整理好继续下一圈

嵌套循环：循环里套循环

2遍历数组与 length

一句话版

🔑 记住这句话遍历 = 用 for 循环配合下标，把数组每个格子挨个访问一遍。循环次数让 length 告诉你，别手写数字。

标准遍历写法（必须背下来）

int[] arr = {10, 20, 30, 40, 50};
for (int i = 0; i < arr.length; i++) {

int[] arr = {10, 20, 30};

// 现在数组变成 {15, 25, 35}

int[] arr = {10, 20, 30};

3数组三大统计：求和、最值、平均

一句话版

🔑 记住这句话数组统计的套路只有一个：循环前准备一个"记录变量"，遍历中不断更新它，循环后它就是答案。

① 求和（累加器套路）

int[] arr = {88, 92, 56, 77, 100};
int sum = 0;                       // 循环前：累加器清零
for (int i = 0; i < arr.length; i++) {
    sum += arr[i];                 // 循环中：每个元素累加进去
}
System.out.println("总分：" + sum);   // 循环后：413

② 求平均值（注意 int 除法的坑）

double avg = (double) sum / arr.length;  // 强转保留小数（2-4 的知识）
System.out.println("平均分：" + avg);      // 82.6

③ 求最大值（打擂台）

生活类比：打擂台。先让第一个人当擂主，后面的人依次上台挑战，谁更强谁留下。

int[] arr = {88, 92, 56, 100, 77};
int max = arr[0];   // 擂主：先假设第 1 个元素最大
for (int i = 1; i < arr.length; i++) {
    if (arr[i] > max) {   // 挑战者更强？
        max = arr[i];        // 换擂主
    }
}
System.out.println("最高分：" + max);  // 100

最小值同理：擂主初值 arr[0]，条件改成 arr[i] < min。

💡 两个小细节① max 初值不要写 0——如果全班成绩都为负分，0 反而成了"最大值"，用 arr[0] 最稳妥。② i 从 1 开始即可（自己不用和自己比），从 0 开始也不会错。

④ 顺带记录"最值的位置"

int max = arr[0];
int maxIndex = 0;              // 记录擂主的下标
for (int i = 1; i < arr.length; i++) {
    if (arr[i] > max) {
        max = arr[i];
        maxIndex = i;           // 更新值的同时记住位置
    }
}
System.out.println("最高分在第 " + (maxIndex + 1) + " 位");

求和sum = 0sum += arr[i]

最大值max = arr[0]更大就替换
最小值min = arr[0]更小就替换

4查找与冒泡排序

一句话版

🔑 记住这句话查找 = 遍历一遍逐个比对；冒泡排序 = 相邻两个元素两两比较，大的（或小的）一步步"冒"到末尾。

① 顺序查找：一个值在不在数组里

int[] arr = {88, 92, 56, 77, 100};
int target = 56;
int index = -1;          // -1 表示"没找到"（数组下标不可能是 -1）
for (int i = 0; i < arr.length; i++) {
    if (arr[i] == target) {
        index = i;         // 找到了，记下位置
        break;           // 找到就提前收工
    }
}
if (index == -1) {
    System.out.println("没找到");
} else {
    System.out.println("找到了，下标是 " + index);
}

"用 -1 表示没找到"是编程里的经典约定，因为合法下标永远 ≥ 0。

② 冒泡排序：相邻比较，大的沉底

把数组 {5, 3, 8, 1} 从小到大排。第 1 轮让相邻两个比较，左边大就交换：

初始：  5  3  8  1
第1次： 3  5  8  1    （5和3比，交换）
第2次： 3  5  8  1    （5和8比，不动）
第3次： 3  5  1  8    （8和1比，交换）→ 最大值 8 冒到末尾！

每一轮都把当前最大值"冒泡"到最后。一轮排好一个，n 个元素最多做 n-1 轮。

int[] arr = {5, 3, 8, 1};
for (int i = 0; i < arr.length - 1; i++) {        // 轮数：n-1 轮
    for (int j = 0; j < arr.length - 1 - i; j++) { // 每轮比较，-i 因为末尾 i 个已排好
        if (arr[j] > arr[j + 1]) {              // 左边比右边大 → 交换
            int temp = arr[j];
            arr[j] = arr[j + 1];
            arr[j + 1] = temp;
        }
    }
}
// 排序后：1 3 5 8
🔑 交换两个变量必须借助第三个变量temp = a; a = b; b = temp; 这三行是固定套路，就像交换两个杯子里的水必须再拿一个空杯子。

③ 偷懒利器：Arrays.sort（知道有这个工具）

import java.util.Arrays;   // 文件顶部导入

int[] arr = {5, 3, 8, 1};
Arrays.sort(arr);           // 一行搞定：升序排列
System.out.println(Arrays.toString(arr)); // [1, 3, 5, 8]，直接打印数组内容
  • Arrays.toString(数组) 解决了 4-2 说的"直接打印数组是地址串"问题
  • 冒泡要能手写理解原理；实际开发排序直接用 Arrays.sort()，这叫"先懂原理，再用工具"
✅ 板块 4-4 检查题
  1. 顺序查找时为什么用 -1 表示没找到？
  2. 不用第三个变量，直接 a=b; b=a; 能交换吗？结果是什么？
  3. Arrays.sort 排完序是升序还是降序？Arrays.toString 解决什么问题？
👀 查看参考答案
1. 因为数组合法下标都 ≥ 0，-1 不可能与真实下标冲突，是约定俗成的"未找到"标记。
2. 不能。a=b 后 a 原来的值已经丢失，两个变量都变成 b 的值，交换失败。必须用 temp 暂存。

1方法是什么：给代码段起个名字

一句话版

🔑 记住这句话方法（method）= 一段有名字的代码，写一次，可以反复"喊名字"调用，还能接收原料、吐出结果。

生活类比：奶茶店的配方

"做一杯珍珠奶茶"需要十几个动作：加茶、加奶、加珍珠、封口……店员不会每次都重新发明流程，店里有一张配方卡，客人点单（调用）时照卡做一杯。方法就是这张配方卡：

  • 定义方法 = 把配方写好贴在墙上（写一次）
  • 调用方法 = 客人喊"来一杯"，照配方执行（可重复无数次）
  • 参数 = 客人的规格：糖度、冰量（每次可以不同）
  • 返回值 = 做好递给你的那杯奶茶（方法的产出）

没有方法的痛苦（你在第 4 章已经体会过）

成绩分析器的 main 里：录入、求和、求最值、统计、排序……全挤在一起，100 多行。想在两个地方各算一次平均分，只能把那 5 行代码复制粘贴两遍——代码就像只能"复制粘贴零件"的机器，又长又难改。

方法的两大好处

好处说明
复用一段逻辑写一次，到处调用；改逻辑只改一个地方
清晰main 变成"总调度"：inputScores(); printReport();——读名字就知道程序在干嘛

先看一个成品（5-2 细讲语法）

public class MethodFirst {
    public static void printWelcome() {       // 定义方法
        System.out.println("欢迎光临！");
        System.out.println("今天也要加油哦");
    }

    public static void main(String[] args) {
        printWelcome();   // 调用：喊名字 + 小括号
        printWelcome();   // 再调用一次，同样两行输出，无需复制代码
    }
}

注意：现阶段所有自定义方法都先加上 static（和 main 一样），原因等第 6 章学完对象自然明白，现在照抄。

2定义与调用（无参无返回值）

一句话版

🔑 记住这句话最简单的方法：不取原料、不递结果，只负责做一件事，写法固定 public static void 方法名()。

方法定义的完整语法位置

public class 类名 {

    public static void 方法名() {
        // 方法体：这个方法要做的事
    }

    public static void main(String[] args) {
        方法名();   // 在 main 里调用
    }
}
  • 方法定义在类里面、main 的外面（和 main 平级，不能写在 main 的大括号里面）
  • void 表示"空"——这个方法不返回任何结果，只做动作
  • 方法名遵守小驼峰：printMenu、drawLine，建议用"动词+名词"

完整例子：打印分割线

public class LineDemo {
    public static void printLine() {
        System.out.println("==============");
    }

    public static void main(String[] args) {
        printLine();
        System.out.println("成绩单标题");
        printLine();
        System.out.println("小明：90分");
        printLine();
    }
}

想把分割线改成 20 个等号？只改方法体一处，三处调用全部生效——这就是复用。

执行顺序：调用即"跳转"

main:  ①printLine(); ──跳转到方法体执行完──┐
       ②println("成绩单标题")                 │ 回到 main 继续
       ③printLine(); ──再跳转一次──────────┘

调用方法时，程序会跳进方法体逐行执行，执行完跳回调用处，接着往下走。

方法可以调用方法

public static void printHeader() {
    printLine();                    // 一个方法里调用另一个方法
    System.out.println("学生管理系统");
    printLine();
}
public static void main(String[] args) {
    printHeader();
}
⚠️ 新手三个高频错 ① 方法定义套在 main 里面（大括号嵌套错位）——方法必须和 main 平级。
② 调用时只写 printLine 忘了小括号——必须 printLine();。
③ 在方法体外面写执行语句——能执行的语句只能待在某个方法体里。

1. void 表示方法不返回任何结果；骨架：public static void 方法名() { 方法体 }。

3参数与返回值：方法的"入口"和"出口"

一句话版

🔑 记住这句话参数让方法每次处理不同的数据；返回值让方法把计算结果交还给调用处。

带参数的方法

// 定义：小括号里声明"形参"（形式上的参数）——需要一个 int，起名 n
public static void printWelcome(String name, int count) {
    for (int i = 0; i < count; i++) {
        System.out.println("欢迎你，" + name);
    }
}

public static void main(String[] args) {
    printWelcome("小明", 3);   // 调用：传入"实参" 小明→name，3→count
    printWelcome("小红", 1);   // 同一段逻辑，换数据再用
}
形参实参
在哪定义方法时的小括号里调用方法时的小括号里
是什么"占位变量"：(String name)真实数据："小明"
要求个数、顺序、类型必须一一对应

带返回值的方法

// void 改成 int：承诺会"吐出"一个 int 结果
public static int add(int a, int b) {
    int result = a + b;
    return result;      // return 把结果送回调用处，方法立即结束
}

public static void main(String[] args) {
    int sum = add(3, 5);  // 方法返回 8，被 sum 接住
    System.out.println(sum);             // 8
    System.out.println(add(10, 20) * 2);  // 返回值可以直接参与运算：60
}
  • 返回类型不是 void 时，方法里必须有 return，且 return 的值类型要匹配
  • return; 一执行方法立刻结束，后面的代码不会再跑（像 break 但作用于方法）
  • void 方法里也可以写不带值的 return; 提前结束（少用）

综合例子：判断成年

public static boolean isAdult(int age) {
    if (age >= 18) {
        return true;     // 条件成立，返回 true 并结束
    }
    return false;        // 否则返回 false
}

public static void main(String[] args) {
    if (isAdult(20)) {    // 返回值直接当布尔条件用
        System.out.println("可以进入");
    }
}

return vs println（最容易混淆）

System.out.printlnreturn
作用把字打印到屏幕给人看把值交回给程序内部使用
之后程序继续运行方法立即结束
能赋值给变量吗不能能：int s = add(1,2);

  2. 形参和实参分别在哪里？调用时要注意什么？
  3. 方法声明返回类型是 double，方法体里 return 一个 int 行不行？
👀 查看参考答案
1. public static int max(int a, int b){ return a > b ? a : b; }（或 if 判断后 return）。
2. 形参在定义时的小括号里（占位变量），实参在调用时的小括号里（真实数据）；个数、顺序、类型必须对应。

4方法重载：同名方法的不同"胃口"

一句话版

🔑 记住这句话同一个方法名，可以定义多个版本，只要参数列表不同——调用时 Java 按你传的参数自动选版本。这叫重载（overload）。

为什么需要重载

想做"两个数相加"：两个 int、两个 double、三个 int……如果没有重载，得起 add2Int、add2Double、add3Int 一堆名字，难记。重载让它们都叫 add。

完整例子

public static int add(int a, int b) {
    return a + b;
}
public static double add(double a, double b) {   // 参数类型不同
    return a + b;
}
public static int add(int a, int b, int c) { // 参数个数不同
    return a + b + c;
}

public static void main(String[] args) {
    System.out.println(add(1, 2));       // 自动匹配第 1 个：3
    System.out.println(add(1.5, 2.5));   // 自动匹配第 2 个：4.0
    System.out.println(add(1, 2, 3));    // 自动匹配第 3 个：6
}

重载的判断规则（三看）

必须不同（满足其一即可）不同也不算重载
参数个数不同仅返回类型不同（int f() 和 double f() 冲突！）
参数类型不同仅参数名字不同（f(int a) 和 f(int b) 完全一样）
参数类型的顺序不同只有方法体不同

记忆：重载只认方法名相同 + 参数列表不同，和返回值、参数名无关。

你其实早就见过重载

System.out.println(100);      // int 版
System.out.println(3.14);     // double 版
System.out.println("你好");  // String 版
System.out.println(true);     // boolean 版

println 就是靠重载，才能"什么类型都能打印"。你写 printInt、printDouble 多累，Sun 公司的设计师早替你想好了。

✅ 板块 5-4 检查题
  1. 方法重载的两个条件是什么？返回类型不同算重载吗？
  2. void f(int a) 和 void f(int b) 能构成重载吗？
  3. 举出一个你天天在用的重载例子。
👀 查看参考答案
1. 方法名相同且参数列表不同（个数/类型/类型顺序不同）。不算，只改返回类型会报"方法已定义"的冲突错误。
2. 不能，参数名不同但列表实质相同（都是一个 int），编译器认为是重复定义。
3. System.out.println 有 int/double/String/boolean 等多个重载版本。

5数组作为参数与返回值

一句话版

🔑 记住这句话数组也能传给方法、从方法返回。传数组时传的是"同一排柜子的位置"，方法里改动元素，外面真的会变。

数组作为参数

public static void printArray(int[] arr) {   // 形参：int[] 类型
    for (int i = 0; i < arr.length; i++) {
        System.out.print(arr[i] + " ");
    }
    System.out.println();
}

public static int getSum(int[] arr) {
    int sum = 0;
    for (int x : arr) { sum += x; }
    return sum;
}

public static void main(String[] args) {
    int[] scores = {88, 92, 56};
    printArray(scores);        // 实参直接写数组名，不加 []
    System.out.println(getSum(scores));  // 236
}

方法内修改数组元素：外面跟着变

public static void addFive(int[] arr) {
    for (int i = 0; i < arr.length; i++) {
        arr[i] += 5;     // 改的是"同一排柜子"
    }
}

public static void main(String[] args) {
    int[] a = {1, 2, 3};
    addFive(a);
    System.out.println(a[0]);  // 6！main 里的数组被改变了
}

对比基本类型：把 int 变量传进方法，方法里改的是复印件，外面不变；数组传的是柜子的位置，方法拿到位置后打开的是同一排柜子，改动会带回来。（现阶段记住现象即可，第 6 章会讲"引用"这个概念。）

数组作为返回值

// 返回一个装着 1~n 的数组
public static int[] makeArray(int n) {
    int[] arr = new int[n];
    for (int i = 0; i < n; i++) {
        arr[i] = i + 1;
    }
    return arr;            // 返回类型写 int[]
}

public static void main(String[] args) {
    int[] data = makeArray(5);   // 接住返回的数组
    printArray(data);             // 复用上面的打印方法：1 2 3 4 5
}

1类与对象：图纸与房子

一句话版

🔑 记住这句话类（class）是一张设计图纸，对象（object）是按图纸盖出来的房子；一张图纸可以盖出很多栋各有门牌的房子。

从"面向过程"到"面向对象"

前 5 章你写代码的视角是"第一步、第二步、第三步"——这叫面向过程，脑子里想的是"流程"。但现实世界是由一个个东西组成的：学生、图书、订单。面向对象让你换视角：先描述"书是什么、能做什么"，再让具体的书对象自己工作。

概念类比例子

// Student.java —— 这是一张"学生图纸"
public class Student {

用图纸创建对象并使用

// TestStudent.java（或同一个类的 main 中）
public class TestStudent {
    public static void main(String[] args) {
        Student s1 = new Student();   // 按图纸造一个学生对象
        s1.name = "小明";             // 用 点. 给属性赋值

        s1.study();                      // 用 点. 调用行为：小明 正在学习

        s2.name = "小红";
        s2.age = 17;
        s2.study();                      // 小红 正在学习
    }
}

  • 对象.属性 访问数据，对象.方法() 调用行为，这个点读作"的"：s1 的 name
  • s1、s2 是两个独立对象，互不影响

2成员变量、局部变量与成员方法

一句话版

🔑 记住这句话写在类里方法外的是成员变量（每个对象一份）；写在方法里的是局部变量（方法结束就消失）。成员方法能直接使用本对象的成员变量。

两种变量对比

public class Student {
    String name;     // 成员变量：类里方法外，对象的一部分，有默认值

    public void sayHi(String prefix) {   // prefix 是局部变量（参数）
        int times = 3;                // 局部变量：方法里，无默认值，必须先赋值
        for (int i = 0; i < times; i++) { // i 也是局部变量
            System.out.println(prefix + "，我是 " + name);
        }
    }
}
成员变量局部变量

3封装：给数据装上"闸门"

一句话版

🔑 记住这句话封装 = 用 private 把属性藏起来，只允许通过公开的 get/set 方法访问，在方法里把关数据的合法性。

不封装会怎样

Student s = new Student();
s.age = -100;    // 年龄变成 -100，程序照样运行——数据荒唐，但没人拦

就像把家里存折放在门口鞋柜上，谁路过都能改金额。封装的思路：属性不对外裸露，想改必须经过我设的窗口，窗口里有安检。

封装三步

① private 私有化属性

public class Student {
    private String name;   // private：只有本类内部能直接碰
    private int age;
}

此后在类外面写 s.age = -100; → 直接编译报错，age has private access。

② 提供 public 的 get/set 窗口

public void setAge(int a) {
    if (a >= 0 && a <= 150) {   // ③ 安检：合法才放行
        age = a;
    } else {
        System.out.println("年龄不合法：" + a);
    }
}
public int getAge() {
    return age;
}
public void setName(String n) { name = n; }
public String getName() { return name; }
Student s = new Student();
s.setAge(-100);          // 打印"年龄不合法"，属性不被污染
s.setAge(18);
System.out.println(s.getAge());  // 18

getter/setter 命名约定

属性读（getter）写（setter）
namegetName()setName(String name)
agegetAge()setAge(int age)

布尔属性的 getter 习惯用 is 开头：isVip()。IDEA/VS Code 都有"自动生成 get/set"功能（Alt+Insert / 右键源码操作），工作里不会手写，但现在请先手写理解。

封装的好处（背下来）

  • 安全：挡住非法数据（负年龄、空姓名）
  • 可控：内部实现以后改了（比如 age 改成存生日），外面调用 getAge 的代码不用动
  • 清晰：对象自己的数据自己负责，符合面向对象思想
💡 记忆口诀属性私有（private），方法公开（public），读用 get、写用 set，set 里做校验。

4构造方法与 this：new 对象时的"初始化流程"

一句话版

🔑 记住这句话构造方法是 new 对象时自动调用的"初始化方法"，负责出生时就把属性填好；this 代表"当前这个对象自己"。

没有构造方法的麻烦

Student s = new Student();
s.setName("小明");   // 造对象 1 行 + 填属性 N 行
s.setAge(18);

能不能"出生时一次性把名字年龄都报上"？构造方法就是干这个的。

构造方法的格式（三要素）

public class Student {
    private String name;
    private int age;

    public Student(String name, int age) {   // 构造方法：①名字与类名完全相同 ②没有返回类型 ③通常 public
        this.name = name;     // this.name 是成员变量；name 是参数
        this.age = age;
    }
}
Student s = new Student("小明", 18);   // new 时自动调用，一步完成初始化

this 的两个核心用法

用法含义例子
this.属性当前对象的成员变量（解决与参数同名）this.name = name;
this(...)本类中调用另一个构造方法（必须放第一行）this("无名", 0);

没有 this 时 name = name; 两边都被当成参数，成员变量根本没被赋值。this 就是在说"把参数 name 放进我这个对象的 name 格子"。

无参构造 & 构造方法重载

public Student() {              // 无参构造：给默认值
    this.name = "未命名";
    this.age = 0;
}

public Student(String name) {    // 重载：只给名字
    this.name = name;
    this.age = 18;
}

public Student(String name, int age) {  // 全参构造
    this.name = name;
    this.age = age;
}
Student a = new Student();
Student b = new Student("小红");
Student c = new Student("小刚", 20);
⚠️ 关键规则 ① 任何类默认自带一个无参构造；但一旦你写了有参构造，默认无参构造就消失了，还想用 new Student() 就必须自己补一个。
② 构造方法不能像普通方法那样被对象调用（s.Student() 非法），它只在 new 时自动执行一次。

标准 JavaBean 的完整长相（章项目照这个写）

1继承 extends：儿子复用爸爸的东西

一句话版

🔑 记住这句话继承让子类自动拥有父类的非 private 属性和方法，重复代码只在父类写一次。用 extends 关键字。

为什么需要继承

公司里有全职员工、兼职员工、经理……他们都有姓名、工号，都能打卡。如果每个类各写一遍 name、id、clockIn()，代码三份重复。观察现实：这些类"是一种"员工——把共性抽到父类 Employee，他们各自继承它。

// 父类（基类）
public class Employee {
    protected String name;   // protected：子类也能访问
    protected String id;

    public void clockIn() {
        System.out.println(name + "(" + id + ") 打卡成功");
    }
    // getter/setter、构造方法省略，按第6章规范写
}

// 子类：全职员工"是一种"员工
public class FullTimeEmployee extends Employee {
    private double monthlySalary;  // 子类只写自己特有的
    // name、id、clockIn() 全部自动继承过来，不用再写！
}
FullTimeEmployee f = new FullTimeEmployee();
f.setName("小明");      // setName 是从父类继承来的
f.clockIn();             // 小明(...) 打卡成功

继承的规则与术语

术语含义
父类 / 子类（超类/派生类）被继承者 Employee / 继承者 FullTimeEmployee
能继承什么非 private 的属性和方法（构造方法不被继承，但子类构造会先调用它）
单继承Java 一个类只能 extends 一个父类（一个亲爹），但可以多层：A→B→C
根类所有类默认直接/间接继承 Object

super：子类构造里先"安顿好父类"

public class Employee {
    public Employee(String name, String id) {
        this.name = name;
        this.id = id;
    }
}
public class FullTimeEmployee extends Employee {
    private double salary;
    public FullTimeEmployee(String name, String id, double salary) {
        super(name, id);        // 调用父类构造，必须在第一行
        this.salary = salary;
    }
}
  • super(...) 调用父类构造；super.方法() 调用父类方法（7-2 用）
  • 子类构造默认第一行先 super()；父类没有无参构造时，必须显式写 super(参数)，否则编译报错

什么时候该用继承？

判断口诀："is-a"——能说"全职员工是一种员工"才用继承。"汽车有轮胎"是 has-a 关系（成员变量），不要让 Car extends Tire。

2方法重写：继承来的方法不合身？改写它

一句话版

🔑 记住这句话子类对继承来的方法不满意，可以写一个同名同参数的"新版本"覆盖它，这叫重写（Override）。

例子：不同员工发工资算法不同

public class Employee {
    protected String name;
    public void showPay() {
        System.out.println(name + " 的工资按通用规则计算");
    }
}

public class FullTimeEmployee extends Employee {
    private double monthlySalary;

    @Override                          // 注解：声明"我要重写父类方法"
    public void showPay() {
        System.out.println(name + "（全职）月薪：" + monthlySalary);
    }
}
FullTimeEmployee f = new FullTimeEmployee();
f.setName("小明");
f.showPay();   // 小明（全职）月薪：... → 执行的是子类新版本

重写的要求（@Override 会帮你检查）

  • 方法名、参数列表必须完全相同；返回类型相同（或子类型）
  • 子类方法权限不能比父类更严（父类 public，子类不能 protected）
  • 建议加 @Override：一旦你名字打错（比如写成 showPa y），编译器立刻报错，而不是悄悄变成"新方法"

super.方法：复用而不是全推翻

@Override
public void showPay() {
    super.showPay();   // 先执行父类版本
    System.out.println("全职员工另有五险一金说明");  // 再追加子类内容
}

重写 vs 重载（必考对比）

重写 Override（@Override）重载 Overload
发生位置父子类之间同一个类里
方法名相同相同
参数列表必须相同必须不同
目的父类版本不适合子类，覆盖改造同名方法处理不同参数

3向上转型与多态：同一句指令，不同反应

一句话版

🔑 记住这句话父类引用指向子类对象（向上转型），调用被重写的方法时，执行哪个版本看 new 的是谁——这就是多态。

生活类比

老师喊一声"交作业！"（同一个指令）：学霸交的是手写论文，普通同学交练习册，课代表收齐后还要统计。指令相同，不同对象反应不同——多态（polymorphism，"多种形态"）。

向上转型语法

Employee e1 = new FullTimeEmployee("小明", "E001", 8000);
Employee e2 = new PartTimeEmployee("小红", "E002", 50, 20);
e1.showPay();   // 执行全职版算法
e2.showPay();   // 执行兼职版算法（时薪×工时）

左边"看起来"是 Employee（父类引用），右边实际是子类对象。就像说"过来一个人"，来的其实是小明（人 是父类型，小明 是具体的人）。

多态的威力：一个方法服务所有子类

// 不用多态：每加一种员工，就要改一遍发薪代码
public static void pay(Employee e) {   // 参数写成父类
    e.showPay();    // 运行时自动按真实对象调用对应版本
}

public static void main(String[] args) {
    pay(new FullTimeEmployee(...));
    pay(new PartTimeEmployee(...));
    pay(new Manager(...));       // 以后新增经理类，pay 方法一行都不用改！
}

这就是多态最实际的价值：扩展性。章项目里发薪循环将极其简洁。

多态的三个前提（缺一不可）

  1. 有继承（或实现接口，7-5）
  2. 有方法重写
  3. 父类引用指向子类对象：父类 变量 = new 子类();

成员变量与静态方法不"多态"（注意陷阱）

Employee e = new FullTimeEmployee();
e.showPay();          // 成员方法：编译看左、运行看右（多态，跑子类版）
System.out.println(e.name); // 成员变量：看左边，按父类的来

现阶段记住：多态只针对被重写的实例方法。另外向上转型后，不能直接调用子类独有的方法（编译看左边，Employee 没有 monthlySalary 相关方法）。

instanceof 与向下转型（了解，章项目选做）

if (e instanceof Manager) {        // 判断 e 的真实身份是不是经理
    Manager m = (Manager) e;        // 向下转型后才能调用经理特有方法
    m.meeting();
}

4抽象类：只定规矩、不干活的父类

一句话版

🔑 记住这句话用 abstract 修饰的方法只有声明没有方法体，它在说"子类必须会这件事，但怎么做你们自己定"；含抽象方法的类必须是抽象类。

为什么需要抽象

"员工"是个笼统概念：现实中没有"一个普通员工"这种具体东西，只有全职、兼职、经理。但"每个员工都必须能算工资"这件事必须统一规定。那就让父类只立规矩：

public abstract class Employee {
    protected String name;

    public abstract double calcSalary();   // 抽象方法：没有 {}，以分号结束

    public void clockIn() {                 // 抽象类里也可以有普通方法
        System.out.println(name + " 打卡");
    }
}
public class FullTimeEmployee extends Employee {
    @Override
    public double calcSalary() {      // 子类必须重写，否则自己也得声明 abstract
        return 8000;
    }
}

抽象类的规则

规则说明
不能 newnew Employee() 编译报错——抽象概念不能造实物
类有抽象方法 → 类必须 abstract但抽象类里可以一个抽象方法都没有
子类要么重写全部抽象方法，要么自己也是抽象类"规矩必须有人兑现"
可以有构造方法、普通方法、成员变量给子类 super(...) 调用

抽象类 + 多态的标准搭配

Employee[] staff = {
    new FullTimeEmployee(...),
    new PartTimeEmployee(...),
};
double total = 0;
for (Employee e : staff) {
    total += e.calcSalary();   // 每个对象算各自的工资，父类只管"都得有这方法"
}

抽象类的价值：强制设计规范。你在父类立了 calcSalary 的规矩，任何新员工类型忘记实现，编译器立刻不答应。

5接口：极致的"行为契约"

一句话版

🔑 记住这句话接口（interface）是一份纯粹的行为契约：只约定"能做什么"，完全不管"是谁、怎么做"；类用 implements 履行契约。

生活类比：插座标准

国标插座只规定"插头长什么样、几个孔"（契约），不关心你接的是台灯还是空调。任何电器只要做成国标插头（implements），就能插进任何国标插座。接口让不相关的类也能拥有同一套行为标准。

定义与实现

public interface Payable {
    double calcSalary();   // 接口方法默认 public abstract，不用写方法体
}

public class FullTimeEmployee implements Payable {
    @Override
    public double calcSalary() { return 8000; }
}
  • 接口不能 new；实现类必须重写接口的全部抽象方法
  • 一个类只能继承一个父类，但可以实现多个接口（用逗号隔开）：class Manager extends Employee implements Payable, Meeting——弥补单继承的局限

接口的多态（最常见用法）

Payable p1 = new FullTimeEmployee(...);   // 接口引用指向实现类对象
System.out.println(p1.calcSalary());

方法参数写成接口类型 void pay(Payable p)，那么任何实现了 Payable 的对象都能传进来——员工能传，以后"外包顾问""兼职模特"只要 implements Payable 也能传。

接口 vs 抽象类

接口 interface抽象类 abstract class
关系含义has-a 能力："能支付工资"is-a："是一种员工"
数量可实现多个只能继承一个
成员变量只能是常量（了解）普通属性都可以
构造方法没有有
选择定义跨类型的行为标准/能力有共性代码和属性要复用

Java 8+ 接口里还能写 default 方法和 static 方法，现阶段知道有这回事即可，章项目用不上。

5try-catch-finally：给意外备好"安全网"

一句话版

🔑 记住这句话把可能出事的代码放 try，出了对应异常由 catch 接住处理，finally 无论是否出事都会执行。

基本语法

try {
    // 可能出异常的代码
    int[] arr = {1, 2, 3};
    System.out.println(arr[5]);
    System.out.println("try 里异常之后的语句不会执行");
} catch (ArrayIndexOutOfBoundsException e) {
    // 出了这种异常时怎么办
    System.out.println("下标越界了：" + e.getMessage());
}
System.out.println("程序没有崩溃，继续往下走");

执行路径：try 正常 → catch 整段跳过；try 出事 → 跳到匹配的 catch，try 剩余语句不执行。无论哪条路，catch 之后的代码都照常运行。

多个 catch：不同意外不同处理

try {
    int n = sc.nextInt();
    System.out.println(100 / n);
} catch (InputMismatchException e) {
    System.out.println("请输入整数！");
} catch (ArithmeticException e) {
    System.out.println("不能输入 0！");
} catch (Exception e) {
    System.out.println("发生了其他意外：" + e.getMessage());
}
  • catch 顺序：子类异常在前，父类 Exception 兜底在最后，否则编译报错（父类在前会把子类也接走）
  • e.getMessage() 取简短原因；e.printStackTrace() 打印完整红色堆栈（调试用）

finally：无论如何都执行

Scanner sc = new Scanner(System.in);
try {
    int n = sc.nextInt();
    System.out.println(10 / n);
} catch (Exception e) {
    System.out.println("输入有误");
} finally {
    sc.close();    // 关闭资源：正常、异常都会执行（了解）
}

finally 主要用于关闭文件、数据库连接等资源；Scanner 小程序不关也没关系，知道"finally 必执行"即可。

try-catch vs if 防御（怎么选）

场景选择
除零、下标范围、空集合判断优先 if 防御（简单、清晰）
用户键盘输入类型不可控try-catch 包裹 nextInt（8-6 的重点）
⚠️ 不要吞异常catch 块里什么都不写（空块）会把错误悄悄藏起来，程序行为诡异还查不到原因。至少打印一条提示。

6让输入更健壮：输不错不罢休

一句话版

🔑 记住这句话while 循环 + try-catch：输入合法才放行，输入错误就提示并重新输入。这是菜单类程序的"专业级写法"。

问题回顾

ATM 里菜单要 int，用户敲个字母 → nextInt 抛 InputMismatchException → 程序直接崩溃。真实软件不可能这样：微信转账输错内容只会红字提示让你重输。

封装一个"保证得到整数"的方法

// 循环 + 异常：不拿到合法整数不出方法
public static int inputInt(Scanner sc, String tip) {
    while (true) {
        System.out.print(tip);
        try {
            return sc.nextInt();      // 输入合法：直接返回，循环结束
        } catch (InputMismatchException e) {
            System.out.println("输入无效，请输入整数！");
            sc.next();   // 关键！吃掉刚才那段非法输入，否则它一直留在缓冲区死循环
        }
    }
}
⚠️ 最容易漏的一行异常后必须 sc.next()（或 nextLine）把非法 token 取走。不取走，下一轮 nextInt 读到的还是那串字母，继续抛异常 → 无限打印错误提示。

带范围校验的菜单选择

public static int inputChoice(Scanner sc, int min, int max) {
    while (true) {
        int n = inputInt(sc, "请选择(" + min + "-" + max + ")：");
        if (n >= min && n <= max) {
            return n;                // 既要是整数，又要在菜单范围内
        }
        System.out.println("没有这个选项，请重新输入");
    }
}

在菜单程序中使用

    System.out.println("1.添加 2.查看 3.删除 4.退出");
    int choice = inputChoice(sc, 1, 4);   // 字母、9 都能挡住，主菜单代码超干净
    switch (choice) {
        case 1: ... break;
        case 4: System.out.println("再见"); return;
    }
}

1时间复杂度与空间复杂度：算法的"油耗"与"占地"

一句话版

🔑 记住这句话写算法不仅要"能跑"，还要"跑得动"——时间复杂度衡量算法随数据量增长要花多少时间，空间复杂度衡量要占多少内存。O(n) 和 O(n²) 的差距，就是电瓶车和法拉利的差距。

为什么需要复杂度？

你写了一个"找数组最大值"的算法，n=10 时大家都是瞬间出结果。但 n=100 万时，有的算法 0.01 秒搞定，有的要 100 秒——这就是复杂度的威力。复杂度是算法的身份证号，面试必考，实战必看。

O(n log n)线性对数~33~10000归并排序、快速排序
O(n²)平方100100 万冒泡排序、嵌套 for
O(2ⁿ)指数~1000天文数字递归求斐波那契（笨办法）

// O(n²)：两个 for 套在一起，执行次数 = n × n
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {

// O(log n)：每次砍掉一半
int left = 0, right = n - 1;
while (left <= right) {
    int mid = (left + right) / 2;

// O(k) 空间：k 是哈希表的大小
HashMap<String, Integer> map = new HashMap<>();

2双指针与数组操作

一句话版

🔑 记住这句话双指针就是两个变量同时指向数组的不同位置，比嵌套循环少一层复杂度。快慢指针、对撞指针、滑动窗口——名字不同，核心都是"两个指针一起干活"。

为什么要双指针？

比如"找出数组里所有和为 target 的两个数"，用嵌套 for 是 O(n²)。用双指针——先排序，然后一头一尾往中间靠——O(n log n) 搞定，快了一万倍。

类型一：对撞指针（两头往中间靠）

// 数组必须先排序！
int[] arr = {1, 3, 4, 6, 8, 10};
int target = 10;
int left = 0, right = arr.length - 1;
while (left < right) {
    int sum = arr[left] + arr[right];
    if (sum == target) {
        System.out.println("找到：" + arr[left] + "+" + arr[right]);
        left++; right--;
    } else if (sum < target) {
        left++;     // 和太小，左指针右移加大
    } else {
        right--;    // 和太大，右指针左移减小
    }
}
⚠️ 铁律对撞指针要求数组有序！无序数组用对撞指针一定会漏解。

类型二：快慢指针（一个走得快，一个走得慢）

最经典的用法是判断链表有没有环（快指针走两步，慢指针走一步，相遇就有环），以及找中间位置（快指针到尾，慢指针就在中间）。

// 找数组中重复的元素（快慢指针思路）
int slow = 0, fast = 0;
do {
    slow = arr[slow];           // 慢指针走一步
    fast = arr[arr[fast]];      // 快指针走两步
} while (slow != fast);
int p = 0;
while (p != slow) { p = arr[p]; slow = arr[slow]; }
System.out.println("重复的数是：" + p);

类型三：滑动窗口（固定/可变长度的窗口在数组上滑）

// 固定长度窗口：求连续 k 个数的最大和
int k = 3;
int sum = 0;
for (int i = 0; i < k; i++) sum += arr[i];  // 先算前 k 个
int max = sum;
for (int i = k; i < arr.length; i++) {
    sum = sum - arr[i - k] + arr[i];   // 窗口滑一格：减去左边，加上右边
    max = Math.max(max, sum);
}

3链表、栈与队列

一句话版

🔑 记住这句话数组是"一排连号储物柜"，链表是"带地址的接力棒"；栈是"堆盘子——后放的先拿"（LIFO），队列是"排队买票——先来的先走"（FIFO）。Java 的 LinkedList 同时实现了栈和队列的接口。

链表：每个节点记住下一个在哪

// 手写一个简单的单向链表节点
class Node {
    int val;
    Node next;          // next 指向下一个节点
    Node(int val) { this.val = val; }
}

// 创建链表：1 → 2 → 3
Node head = new Node(1);
head.next = new Node(2);
head.next.next = new Node(3);

// 遍历链表
Node cur = head;
while (cur != null) {
    System.out.print(cur.val + " ");
    cur = cur.next;
}

数组 vs 链表

操作数组链表
随机访问第 i 个O(1) 直接 arr[i]O(n) 要从头走 i 步
中间插入/删除O(n) 要整体搬移O(1) 只改指针
头部插入/删除O(n)O(1)
空间连续内存每个节点多存一个 next
💡 什么时候用链表？需要频繁在中间/头部插入删除时用 LinkedList；需要随机访问时用 ArrayList。Java 的 LinkedList 底层就是双向链表。

栈 Stack：后入先出（LIFO）

// Java 用 Deque 当栈（官方推荐，比老的 Stack 类好）
Deque<Integer> stack = new ArrayDeque<>();
stack.push(1);        // 压栈
stack.push(2);
stack.push(3);
System.out.println(stack.pop());  // 3（最后进的先出）
System.out.println(stack.peek()); // 2（看栈顶但不弹）
System.out.println(stack.isEmpty());

栈的经典应用：判断括号是否有效

public static boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(') stack.push(')');
        else if (c == '[') stack.push(']');
        else if (c == '{') stack.push('}');
        else if (stack.isEmpty() || stack.pop() != c) return false;
    }
    return stack.isEmpty();
}
// "{[]}" → true，"([)]" → false

队列 Queue：先入先出（FIFO）

// LinkedList 同时实现了 Queue 接口

queue.offer("小红");
queue.offer("小刚");

System.out.println(queue.peek());  // 小红（看队头）

HashMap 经典用法：统计频次

// 统计一句话中每个字符出现的次数
String s = "hello world";
HashMap<Character, Integer> count = new HashMap<>();

    count.put(c, count.getOrDefault(c, 0) + 1);
}
for (Map.Entry<Character, Integer> e : count.entrySet()) {
    System.out.println("'" + e.getKey() + "' 出现 " + e.getValue() + " 次");
}
// 'h' 出现 1 次, 'e' 出现 1 次, 'l' 出现 3 次, 'o' 出现 2 次, ...

HashMap 经典用法：两数之和

// 给定数组和 target，返回两个数的下标，使它们的和等于 target
public static int[] twoSum(int[] nums, int target) {
    HashMap<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int need = target - nums[i];     // 当前数需要找谁配对
        if (map.containsKey(need)) {
            return new int[]{map.get(need), i};  // 找到了！
        }
        map.put(nums[i], i);               // 把当前数存起来
    }
    return new int[]{-1, -1};
}
// nums=[2,7,11,15], target=9 → 返回 [0,1]

    }
});

comments.sort((a, b) -> b.likes - a.likes);

// 找出评论里出现最多的词
HashMap<String, Integer> wordCount = new HashMap<>();
String[] stopWords = {"的", "了", "是", "我", "在"};  // 停用词

for (Comment c : comments) {
    for (String word : c.comment.split("[\\s，。！？、]+")) {
        if (word.length() < 2) continue;  // 太短的跳过
        wordCount.put(word, wordCount.getOrDefault(word, 0) + 1);
    }
}

// 按频次排序后打印 Top 10

sorted.sort((a, b) -> b.getValue() - a.getValue());

✅ 板块 10-3 检查题
  1. HashMap 分组统计的通用套路是什么？（关键词：getOrDefault + put）
  2. Comparator 的 compare 返回正数、负数、0 分别代表什么？
  3. 对 List 排序后，原 List 的顺序会变吗？
👀 查看参考答案
1. map.put(key, map.getOrDefault(key, 0) + 1)——取出旧值（没有就给默认值 0），加 1，再存回去。
2. 返回正数：第一个参数排后面；负数：第一个排前面；0：相等顺序不变。b-a 就是大的在前（降序）。
3. 会变！List.sort() 是原地排序，直接修改原列表。如果不想改原列表，先 new ArrayList<>(原列表) 拷贝一份。
