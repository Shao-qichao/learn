## 👀 预期效果
```
找到：a[?]=... 的组合，例如 12 = 1+11、3+9 等其中一对
目标 100：没找到这样的两个数
```
不管数组多长，两个指针加起来最多走 n 趟，时间 O(n)，只用了固定几个变量，空间 O(1)。

## 💡 提示
和太小就把左指针右移（让和变大），和太大就把右指针左移（让和变小），这个“能判断往哪边走”的前提正是数组有序；无序数组只能先排序或改用哈希表。
