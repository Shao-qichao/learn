## 👀 预期效果
```
()      ->  有效(是)
([])    ->  有效(是)
{[()]}  ->  有效(是)
([)]    ->  无效(否)
(()     ->  无效(否)
)(      ->  无效(否)
```
队列部分依次打印：服务小明 → 服务小红 → 服务小刚。

## 💡 提示
判断括号的诀窍：遇到左括号时，把“它将来需要的那个右括号”压栈；遇到右括号就弹栈比对。Java 官方推荐用 `ArrayDeque` 当栈（`push/pop`），老旧的 `Stack` 类不要再用；同一个 `ArrayDeque` 用 `offer/poll` 就是队列。
