# 4-3 求和/最值/平均

**板块编号：** c4s3　|　**所属：** 第 4 章　|　**练习项目：** `ch04-s03-array-stats`

## 🎯 练习目标
用记录变量的套路完成数组的求和、平均分、最大值和最小值统计。

## 📋 练习步骤
1. 用累加器 sum 遍历求出数组总分
2. 用 (double) sum / arr.length 求出平均分并保留小数
3. 用打擂台法（max 初值取 arr[0]）求出最高分并记录它的下标
4. 把判断改成更小就替换，求出最低分
