## 🎯 练习目标
用 `Comparator` 给评论按点赞数排序，用 `HashMap` 汇总每个人的发言条数，做出“热评榜”和“活跃用户”。

1. 双击 `run.bat`，看按点赞降序的热评榜和每人发言条数

3. 热评榜循环里只打印 `likes >= 2` 的评论，过滤掉 0 赞
4. 排序后 `list.get(0)` 就是最热评论，单独打印“今日最热：…”

## 💡 提示
- `Comparator.compare(a,b)`：返回**负数** a 排前面，**正数** b 排前面，0 相等。所以 `b.likes-a.likes` 是降序，`a.likes-b.likes` 是升序。
- `list.sort(...)` 是原地排序，会直接改变 list 顺序；不想改原列表就先 `new ArrayList<>(list)` 复制一份。
- “分组计数”就是 HashMap：键是昵称，值用 `getOrDefault(名字,0)+1` 累加。
