## 🎯 练习目标
用数组把录入、遍历、求和、最值和分段统计串起来，输出一份成绩分析报告。

## 📋 练习步骤
1. 先用写死的数组 {88, 92, 56, 77, 100} 把总分和平均分算对
2. 用打擂台法补上最高分和最低分，初值取数组第一个元素
3. 用计数器统计及格和不及格人数，并用 if / else if 分四段统计优秀、良好、及格、不及格
4. 把写死的数组改成 Scanner 录入：先输入人数 n，new int[n] 后循环录入 n 个成绩
5. 选做：手写冒泡排序把成绩升序排列后再打印一行
