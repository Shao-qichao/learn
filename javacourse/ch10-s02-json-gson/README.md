可以把这段贴进任意在线 JSON 校验工具验证格式。

## 💡 提示
- JSON 铁律：键和字符串值必须用**双引号**（单引号不合法）；数字、布尔值不加引号；对象用 `{}`、数组用 `[]`；元素之间用逗号，最后一个后面不加。
- 字符串内部要出现双引号时写 `\"`，例如 `"他说\"太棒了\""`；要出现反斜杠写 `\\`。
- 手写拼字符串又累又容易错，真实开发用 Gson：`new Gson().toJson(评论对象)` 一键生成，`fromJson` 一键转回。
