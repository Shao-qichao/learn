## 🎯 练习目标
用 if 和 if-else 让程序按条件二选一执行，理解判断流程与常见写法错误。

## 📋 练习步骤
1. 声明年龄变量，用 if 判断是否大于等于 18 并打印“成年”。
2. 给 if 补上 else 分支，让条件不成立时打印“未成年”。
3. 改小年龄变量的值重新运行，验证走的是 else 分支。
4. 检查条件后面没有多写分号、判断相等用的是两个等号。
