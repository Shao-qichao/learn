# 9-1 时间复杂度与空间复杂度

## 🎯 练习目标
用“循环执行次数计数器”亲手感受 O(n) 与 O(n²) 的差别，看懂只占固定变量的 O(1) 空间。

## 📋 练习步骤
1. 直接双击 `run.bat`，观察表格里 n=5/10/20 时两种循环的执行次数
2. 把 main 里数组的 20 改成 30，先在纸上口算 O(n²) 应该是多少，再运行核对
3. 在 `countLinear` 里加一个 `sum` 变量累加每次的 i，并在 main 打印——只多一个变量，空间仍是 O(1)
4. 用 `//` 注释写下为什么 `O(3n²+2n+1)` 能简写成 `O(n²)`

## 👀 预期效果
```
 n | O(n)执行次数 | O(n^2)执行次数
---|--------------|----------------
 5 |            5 |             25
10 |           10 |            100
20 |           20 |            400
```
n 从 5 涨到 20（4 倍），O(n) 变 4 倍，O(n²) 变 16 倍。

## 💡 提示
复杂度只看“数据量变大时增长多快”：最高阶项决定一切，常数系数和低阶项都扔掉；不管 n 多大、只用到固定几个变量，空间就是 O(1)。
