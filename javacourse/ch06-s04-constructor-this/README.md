## 🎯 练习目标
学会定义构造方法，用 this 区分成员变量与参数，并用 this(...) 复用重载构造。

## 📋 练习步骤
1. 阅读 Student.java，找出构造方法的名字、有没有返回类型，以及 this.name = name 里两个 name 各指什么
2. 在 main 中用无参构造创建 s1，观察它的默认姓名与年龄
3. 用单参构造创建 s2，打印姓名和默认年龄
4. 用全参构造创建 s3，一步完成初始化并打印
5. 对比三种创建方式的输出，总结「有参构造写了，无参构造就要自己补」这条规则
