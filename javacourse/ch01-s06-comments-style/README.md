# 1-6 注释与规范

**板块编号：** c1s6　|　**所属：** 第 1 章　|　**练习项目：** `ch01-s06-comments-style`

## 🎯 练习目标
会用单行和多行注释，按缩进与命名规范写出整洁易读的 Java 代码。

## 📋 练习步骤
1. 用 /* */ 多行注释在代码开头写上程序名和你的名字
2. 在每一条 println 的上方用 // 写一句注释，说明这行输出什么
3. 把其中一行 println 用 // 注释掉，运行确认输出少了一行，然后取消注释
4. 检查缩进是否为 4 个空格一层，格式化后对比前后的可读性
